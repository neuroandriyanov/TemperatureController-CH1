# Проверка исходного комплекта · 07.11.2026

Комплект проверяется отдельно от исходной рабочей папки. Во время подготовки публикации устройства не прошивались и нагрузка не включалась.

## Подтверждённые проверки

| Проверка | Результат |
|---|---|
| Чистое окружение Windows x64 / Python 3.12 | Зависимости установлены из requirements, без старых `.deps` |
| Перенос в отдельный каталог с пробелами | Штатный setup.py, 78 Python-тестов, 54 590 C-проверок и ARM-сборка прошли повторно; BIN совпал |
| Python-тесты | 78: прошивочный клиент 6, ПК-регулятор 31, видеостенд 17, программатор 16, LB02A 8; пропусков нет |
| Native C, MSVC | 54 590 утверждений прошли |
| STM32, Arm GCC 13.3.1 | BIN 35 724 байта, text 35 600, data 124, bss 7 024 |
| SHA-256 STM32 BIN | `93f7d02f7603307c50841d9e405e86e70ddb5882950252f9a2b05ca6973c633c` — совпадает с образом стендовой версии 2.5 |
| ESP32-S3, PlatformIO 6.2.0 / espressif32 6.10.0 | `display-keypad-emulate` собран; Flash 899 097, RAM 226 768 байт |
| Четыре GUI | Открытие/закрытие с пустыми списками устройств, serial запрещён тестовой подменой; программатор проверен и без собранного BIN |
| Карта регистров | Генератор `--check`, копия для ПК совпадает с прошивкой |
| Анализ измерений | Графики пересозданы; статистика и четыре отдельно просмотренные термограммы воспроизведены |
| Очистка измерений | 923 967 числовых/null значений сохранены; 22 фотографии/термограммы сохранили исходные пиксели |

В сохранённых библиотеках ST остаются шесть предупреждений о неиспользованных параметрах; в прикладном коде действует `-Werror`, предупреждений линкера нет. Размер bss включает резерв стека, это не измеренный максимум его использования.

Для малых окон в публикационной копии добавлен перенос строк формы и прокрутка страницы наблюдения: поля/график не перекрываются. Алгоритмы управления и формат протокола не изменены. Явный порт требуется для CLI-операций, вместо личных COM-значений. Путь программатора указывает на текущий результат сборки.

Проверка длинного пути выявила ограничение Windows на ресурсы Qt. Установщик теперь использует короткое окружение в пользовательском LOCALAPPDATA и локальную запись расположения, исключённую из публикации. Проверены отказ CLI без порта и чтение офлайн-статуса через новый launcher. `pip check` не обнаружил конфликтов зависимостей. Обзор `docs/index.html` открыт в браузере: все четыре изображения загружены, на узком экране горизонтального переполнения нет.

## Воспроизведение

```text
python setup.py --dev
python env.py scripts/test.py --native
python firmware/scripts/build.py
python env.py -m platformio run --project-dir apps/calibrator_lb02a/bridge -e display-keypad-emulate
python scripts/knowledge.py --check
```

Linux native-тесты с санитайзерами и ARM-сборка включены в `.github/workflows/ci.yml`, но удалённый GitHub CI в этой подготовке не запускался. Версии действий сверены по первичной документации [actions/checkout](https://github.com/actions/checkout) и [actions/setup-python](https://github.com/actions/setup-python). Сам workflow ничего не прошивает и не публикует.

Программная проверка не означает завершения всех аппаратных испытаний. Список выполненного на реальном стенде и открытых вопросов — [прошивка](../firmware/docs/VALIDATION.md), [опыты](../measurements/README.md), [база знаний](../knowledge/OPEN_QUESTIONS.md).
