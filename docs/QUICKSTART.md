# Первый запуск

## 1. Программы ПК

Установите Python 3.12–3.15 x64 с Tcl/Tk и pip. В терминале откройте корень распакованного проекта и выполните `python setup.py`. На Windows скрипт создаёт короткое окружение в `%LOCALAPPDATA%/CH1/<идентификатор проекта>`, чтобы ресурсы Qt не превышали предел длины пути. На Linux используется `.venv` в проекте. Доступ администратора не требуется. Служебный `.runtime/environment.json` создаётся локально и не публикуется. После перемещения проекта повторите setup; команды `run.py` и `env.py` найдут окружение. `setup.cmd` использует Python Launcher (`py -3`), а при его отсутствии — `python` из PATH. При ошибке зависимости не пропускаются: исправьте причину и повторите установку.

Запуск: `python run.py controller`, `thermal`, `calibrator` или `programmer`. На Windows также есть `start-*.cmd`. Каждое приложение использует отдельное окно. Для разработки: `python setup.py --dev`, затем `python env.py scripts/test.py --native`. `env.py` запускает команды в установленном окружении без ручной активации. Захват DirectShow на Linux недоступен. При нестандартно длинном имени профиля задайте короткую доступную папку через `python setup.py --venv PATH`.

## 2. Собрать STM32

Установите Arm GNU Toolchain для bare-metal Cortex-M с newlib/nano. Достаточно `arm-none-eabi-gcc` в PATH. Альтернатива — переменная `ARM_GCC_DIR` с полным путём к его `bin`; личных путей в исходниках нет. Выполните `python firmware/scripts/build.py`. Файлы появятся в `firmware/build`. Точное имя компилятора, размеры и SHA-256 записываются в `manifest.json`.

Требуемая плата — STM32F030C8T6, 64 КБ Flash и 8 КБ SRAM, с разводкой из [HARDWARE.md](../firmware/docs/HARDWARE.md). Для другой модели/разводки нельзя выбирать прошивку только по похожему названию платы.

## 3. Записать прошивку

Обесточьте силовую нагрузку. Подключите UART-порт загрузки, переведите BOOT0=1 и выполните RESET. В `programmer` выберите **свой** COM-порт; скорость 57600, 8E1. Откройте `firmware/build/controller.bin`, адрес `0x08000000`. «Проверить связь» определяет STM32. «Стереть → записать → проверить» сначала сохраняет резервную копию, затем записывает и сверяет всю Flash; журнал и backup находятся в `apps/stm32_programmer/captures`.

Верните BOOT0=0 и выполните RESET. DTR/RTS на данной плате не переключают BOOT0/RESET. Исходные EEPROM-калибровки при штатном обновлении сохраняются, но у нового устройства должны быть измерены заново.

## 4. Подключить регулятор

RS-485, Modbus RTU **38400, 8E1**. Нужны штатное питание и обычный запуск Flash. Адрес = Sa2 × 16 + Sa3; допустимо 1…247, пример 2/A = 42. Прибор применяет новый адрес после устойчивого положения переключателей и останавливает нагрев при его изменении. Выберите порт и адрес в `controller`, нажмите «Подключить». Настройки читаются из EEPROM/прибора, локальные поля их не подменяют.

Установите реальный тип термопары и компенсацию. Для внешней компенсации температурный диапазон преобразователя должен совпадать с параметрами 4 и 20 мА в приборе. Откалибруйте токовый вход и, при использовании, внешний температурный канал по [CALIBRATION.md](../firmware/docs/CALIBRATION.md). Чужие коэффициенты из отчёта не переносите: это значения одного экземпляра.

Проверьте измерения без нагрева. Калибровочные флаги выставляют после измерений; они не исправляют неверное подключение. Перед силовым пуском задайте технологические пределы, токовые ограничения и подходящий объекту PID. Силовая часть работает от сети; аппаратная термозащита и независимое отключение должны соответствовать вашей установке. Сигнальное K1 не является силовым контактором.

## 5. Управлять и сохранять

AUTO регулирует температуру, MANUAL задаёт долю времени включения. Период пакетного управления — 2…300 с, он не является фазовым углом. Допуски служат для функции реле и не создают мёртвую зону PID. «Применить и запомнить» атомарно сохраняет уставку/допуски; остальные поля — общей кнопкой «Сохранить в прибор» с переходом STOP. Дождитесь подтверждения EEPROM.

При тайм-ауте связи 0 прибор работает автономно и закрытие окна не выключает его. При ненулевом тайм-ауте закрытие окна отправляет STOP; потерю связи обрабатывает контроллер. Сохранённые AUTO/MANUAL/STOP восстанавливаются после питания при готовности датчиков. STOP/F8 останавливает и запоминает STOP. После аварии нужен явный повторный запуск.

## 6. Подключить наблюдение

В `thermal` выберите цветную камеру/карту захвата и UTi260B в отдельных списках. Выберите рабочие видеорежимы. Установите поворот тепловизора согласно креплению, затем выполните совмещение: прозрачность, четыре угла, поворот центральной ручкой, «Сохранить». Оба устройства должны быть закреплены; смена положения или глубины наблюдаемой поверхности нарушает совмещение.

Клик по термограмме создаёт крестик; сохранённая отметка переносится на цветное видео. «Сохранить» пишет две картинки и JSON с данными в `output/bench_monitor`. На зеркальном металле температура по излучению может отражать окружение. Пропуски OSD/декодера отображаются как недоступные, а не заменяются последним числом.
