# База знаний · Temperature Controller CH1

Точка входа для нейроинженера: [index.json](index.json). Здесь собраны версии аппаратуры, источники с SHA-256 и отдельные проверяемые факты в [facts.json](facts.json). Формат близок к базе других проектов NeuroAndriyanov; импорт в работающий сайт автоматически не выполнялся.

Порядок чтения: [архитектура](ARCHITECTURE.md) → [протокол](../firmware/docs/PROTOCOL.md) → [аппаратные ограничения](../firmware/docs/HARDWARE.md) → [опыты](../measurements/README.md) → [открытые вопросы](OPEN_QUESTIONS.md).

Статусы:

- `document_confirmed`: факт явно присутствует в указанном документе/коде/записи. Для лабораторного результата это подтверждает конкретную серию, а не универсальную точность.
- `needs_verification`: есть основание или гипотеза, но нужна физическая/независимая проверка.
- `unknown`: данных нет; значение оставлено `null`.

Каждый факт содержит источник и локатор. Локаторы ссылаются на символ, точную фразу или JSON-поле. Контрольные суммы проверяются `python scripts/knowledge.py --check`. Если исходник намеренно изменён, обновление каталога `--refresh` выполняется отдельно после пересмотра зависимых фактов.

В каталоге указаны репозиторий `neuroandriyanov/TemperatureController-CH1`, конкретный коммит исходного комплекта и постоянные ссылки на файлы. `path` остаётся относительным корню проекта, поэтому проверка SHA-256 работает и офлайн. Для подключения к сайту настройте его разрешённый project_id и адаптируйте локальное расширение `facts` по [FORMAT.md](FORMAT.md); публикация репозитория сама по себе не включает импорт на сайт.
