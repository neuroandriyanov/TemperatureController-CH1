# Локальный формат источников

`schema_version: 1.0`, `project_id: temperaturecontroller_ch1`, `bundle_format: local-hashed-sources-1`.

Основные коллекции `sources`, `hardware_versions`, `components`, `connections` повторяют назначение каталога проектов NeuroAndriyanov. Дополнительный файл `facts.json` хранит программные и экспериментальные факты; это расширение локального пакета, а не заявление о совместимости с существующим серверным импортёром.

Источники: id, title, kind, repository, commit, path, url, sha256, accessed_at, notes. В опубликованном наборе repository содержит `owner/name`, commit — полный SHA коммита с исходником, url — постоянную GitHub-ссылку на этот файл. Относительный path и sha256 позволяют проверять локальную копию без сети. Коммит источника может быть старше текущего HEAD: он фиксирует именно проверенную версию документа. При изменении источника обновляйте его хеш, коммит и ссылку вместе после пересмотра зависимых фактов.

Факты: id, statement, value, unit, status, evidence[{source_id, locator}], notes. Значение null означает отсутствие результата. Статус `document_confirmed` требует evidence; для остальных статусов причина указана в notes. `locator` проверяется как существующая фраза/символ в текстовом источнике; смысл и полнота цитирования дополнительно проверяются человеком/ИИ.

Пока нет независимо сверенного полного netlist, `connections` оставлен пустым. Сигнальные назначения описаны фактами с опорой на HARDWARE.md и исходный код, без выдуманных номеров деталей/контактов. Аппаратные версии разделяют исходную документацию и модифицированный стендовый экземпляр.
