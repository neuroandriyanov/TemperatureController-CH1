# Temperature Controller CH1 — firmware v2

Новая прошивка одноканального регулятора температуры на STM32F030C8T6. Создана на основе разводки и периферийной конфигурации проекта `ssr_cpu_v1`, с новым прикладным кодом измерений, Modbus и PID. В комплект включена только актуальная версия; старый проект не распространяется здесь.

**Версия 2.5 записана на стенд 07.11.2026, вся Flash проверена.** Период пакетного управления симистором — 2–300 секунд; настройки не привязаны к типу нагревателя. Уставка и независимые допуски сохраняются в EEPROM, автономная работа без ПК выбирается через COMM_TIMEOUT_MS=0. Приложение ПК при таком выборе не отправляет STOP при закрытии. Миграция всех 46 прежних настроек и индивидуальной калибровки после обновления проверена. Подробнее о выполненных и ещё не выполненных испытаниях — [VALIDATION.md](docs/VALIDATION.md).

## Возможности

- Термопары B, E, J, K, N, R, S, T через MAX31856, фильтр 50/60 Гц и усреднение.
- Внутренняя компенсация холодного спая либо PT100 через настраиваемый преобразователь 4–20 мА. Диапазон преобразователя, две точки калибровки и поправки доступны через протокол.
- ACS712 **30 А**: AC RMS, коэффициент усиления, поправка, компенсация шума, сырые значения ADC для настройки.
- Режимы STOP, AUTO PID, MANUAL с восстановлением последнего состояния после питания. Ограничение мощности и скорости изменения уставки.
- Modbus RTU **38400, 8E1** через RS-485 и встроенный USB–UART. Выбор адреса двумя штатными шестнадцатеричными переключателями.
- Контроль свежести измерений, ошибок MAX31856, технологических пределов, перегрузки, тока при выключенном выходе, потери связи и ошибок EEPROM. Опциональная диагностика малого тока по накопленным достоверным ON-окнам нескольких пакетов.
- Сохранение в двух записях EEPROM с версией, номером и CRC. Команды AUTO/MANUAL/STOP и изменение мощности в MANUAL сохраняются автоматически; до завершения записи выход выключен.
- K1: выключено, температура в допуске, в допуске после прогрева, любая ошибка, перегрузка, неисправность нагревателя, ошибка прибора. Прогрев начинается при первом попадании в допуск, default 600 с.
- EEPROM формата 2/3/4 мигрирует в формат 5 с 47 настройками. Старые периоды менее 2 с повышаются до 2 с. Из 2.0/2.1 режим восстановления — STOP, из 2.2–2.4 сохраняется прежний режим.
- Период ШИМ 2–300 с; допуски 0–1800 °C с каждой стороны; команда FC16 261…263 запоминает уставку и допуски без смены режима.

После питания прошивка восстанавливает сохранённые AUTO/MANUAL/STOP при готовности датчиков и отсутствии ошибок. После аварии, смены адреса или watchdog сохраняется STOP; неготовность после запуска дольше 15 с отменяет восстановление. Начальные коэффициенты не являются результатом калибровки платы. Пока ток не проверен через `CALIBRATION_FLAGS`, нагрев заблокирован; для внешней компенсации требуется также подтверждение 4–20 мА. Порядок — [CALIBRATION.md](docs/CALIBRATION.md).

## Сборка

Нужны Python 3.9+ и Arm GNU Toolchain с newlib. Зависимостей Python для сборки нет. Команды выполняются из **этой папки**:

```sh
python scripts/build.py
python tests/run.py
python scripts/register_map.py --check
```

Компилятор ищется в `ARM_GCC_DIR`, затем в PATH; на Windows также в стандартном расположении STM32CubeIDE под `C:/ST`. Для явного выбора в PowerShell:

```powershell
$env:ARM_GCC_DIR = 'C:/path/to/arm-toolchain/bin'
python scripts/build.py
```

Native-тесты требуют GCC/Clang либо Visual Studio C++ Build Tools. Для GCC/Clang на Linux: `SANITIZE=1 python3 tests/run.py`. Собираются только нужные проекту библиотеки, находящиеся в `Drivers`; CubeIDE для Linux-сборки не требуется. Workflow расположен в корне комплекта: `.github/workflows/ci.yml`. GitHub CI пока не запускался.

Для примера ПК-клиента: `python -m pip install pyserial`, затем `python examples/client.py PORT --address 1`. Эта команда требует уже работающую новую прошивку, обычный режим BOOT0 и свободный COM-порт. Она не выполняет прошивку и не запускает нагрев.

## Что изменено относительно старой версии

CRC и длина Modbus проверяются до обращения к полям; запись нескольких регистров сначала полностью проверяется. Вместо передачи фрагментов float используются целые числа с явным масштабом. Приём восстанавливается после неверного кадра. STOP и защита по возрасту датчиков работают независимо от появления нового DRDY.

ADC запускается таймером 5000 раз в секунду, а не в непрерывном режиме. RMS рассчитывается по 1000 отсчётам в основном цикле. В прерываниях нет расчёта sqrt/pow. Формула AD7741 использует диапазон частоты 0,05…0,45 от fCLK, то есть размах **0,40**. Исправлено знаковое чтение холодного спая, учитываются ошибки SPI и FAULT.

Нагрев управляется пакетами через GPIO PA3. STOP сразу снимает управление, не ожидая переноса CCR в таймере. SysTick снимает выход при отсутствии завершённых циклов управления более 50 мс; IWDG и внешний WDI остаются дополнительным контролем. Это программные механизмы; их физическое время реакции ещё нужно измерить.
