# Протокол управления 2.4 · прошивка 2.5

Версия 2.5: input 0=0x0205, input 1=0x0204, input 63=47. Для старых карт: 2.0 — 41 настройка, 2.1 — 43, 2.2/2.3 — 46. Прежние адреса сохранены; добавлены holding 46 и команда FC16 261…263.

## Соединение и адрес

Modbus RTU, 38400 бит/с, 8 бит данных, even parity, 1 stop bit (**8E1**). В STM32 это настраивается как 9-битное слово с чётностью, на ПК — как 8E1. RS-485: USART1 PA9/PA10, направление MAX13487 автоматическое. USB FT232: USART2 PA14/PA15. Оба порта обслуживают одну конфигурацию и один регулятор; единственным источником команд запуска и настройки должен быть один мастер. Успешные адресные запросы на любом порту обновляют общий тайм-аут связи.

Адрес = `Sa2 × 16 + Sa3`, оба переключателя FR01FR16H-S на 16 положений. Примеры: `0/1 → 1`, `1/0 → 16`, `2/A → 42`, `F/7 → 247`. `00` и `F8…FF` запрещают запуск и адресные ответы. После изменения контактов выход отключается сразу при следующем проходе основного цикла, адрес применяется после 250 мс без изменений. В период дребезга ответы отключены. Возврат адреса не возобновляет нагрев. Адрес не хранится в EEPROM.

Интервал тишины между кадрами минимум 1,75 мс; разрыв внутри кадра более 0,75 мс делает кадр недействительным. При оценке RXNE учитывается длительность символа. Мастер посылает следующий запрос только после полного ответа и выдержки тишины; для USB рекомендуется пауза не менее 4 мс. Тайм-аут ответа на ПК 500 мс, период опроса 200–500 мс. Сразу после команды сохранения временно допустима задержка из-за EEPROM.

## Формат

Все адреса в документации **с нуля**, без префиксов 3xxxx/4xxxx. Holding address 0 соответствует условному 40001 в программах с таким обозначением; input 0 — 30001.

Регистры 16-битные, старший байт первым. CRC16 Modbus, начальное значение 0xFFFF, полином отражённый 0xA001, в кадре младший байт CRC первым. Числа `s16` — дополнительный код. Например, −10,0 °C при масштабе ×10 передаётся как −100 = `0xFF9C`. Значение float на проводе не используется.

Поля u32 телеметрии занимают два последовательных регистра: старшее слово первым. Исключение — период ШИМ: младшее слово в holding 13, старшее в holding 46 для совместимости прежних адресов. Читать их одним запросом. Телеметрия одного ответа формируется в основном цикле из согласованного состояния; номер преобразования TC позволяет отличать новые данные. Измерительные каналы имеют отдельные отметки времени, поэтому их физические измерения не синхронны.

| Функция | Операция | Ограничения |
|---|---|---|
| 03 | Read Holding Registers | 1…125, весь диапазон должен быть реализован |
| 04 | Read Input Registers | 1…125, реально доступно 0…63 |
| 06 | Write Single Register | Один настройочный регистр или одна команда |
| 16 / 0x10 | Write Multiple Registers | 1…123; вся запись проверяется и применяется целиком |

Неизвестные адреса/пропуски не читаются как нули: ответ exception 02. Команды 256…260 записываются только по одной, в том числе через FC16 с количеством 1. Чтение 258/259 возвращает 0. Команда 260 появилась в карте 2.3 (прошивка 2.4). Нельзя одной операцией пересечь блок настроек и блок команд.

Полный справочник — [REGISTERS.md](REGISTERS.md), машиночитаемая версия — [registers.json](registers.json).

## Настройка и запуск

1. Прочитать input 0…63. Проверить поддерживаемые firmware/protocol (для версии 2.5: 0x0205/0x0204), действующий адрес и режим. Подключение для наблюдения ограничивается чтением: прибор уже может работать после восстановления питания.
2. Записать holding 256 = 0 (STOP). STOP допустим при любых авариях.
3. Прочитать holding 0…46. Изменить параметры. Во время работы разрешены только уставка 0 и допуски K1 18/19; остальные требуют STOP. Holding 45 обновляет прошивка: запись другого значения отклоняется (03); в групповую запись включать текущее значение после STOP.
4. Проверить ток, выбранную термопару и источник компенсации. Выполнить [калибровку](CALIBRATION.md), затем явно подтвердить соответствующие биты holding 40. Изменение коэффициентов автоматически снимает подтверждение соответствующего канала, если регистр 40 не входит в ту же групповую запись.
5. Подождать свежих измерений и убедиться, что input 8/9 (active faults) равны нулю. При зафиксированной аварии отправить holding 259 = 0xC1EA и проверить input 10/11.
6. Для AUTO записать holding 256 = 1. Для MANUAL сначала записать holding 257 = мощность ×100, затем 256 = 2. Ограничение мощности действует и в ручном режиме. Команда STOP обнуляет ручное значение.
7. Опрос продолжать чаще, чем `COMM_TIMEOUT_MS`. По умолчанию при отсутствии успешных запросов более 5 секунд регулятор останавливается и фиксирует аварию. CRC-ошибки, запросы к другим адресам и exception не продлевают тайм-аут.
8. Для остановки отправить STOP. Для автономной работы заранее сохранить holding 29=0, затем закрыть COM-порт без STOP. В приложении ПК флажок «Автономно» выбирает это поведение; при ненулевом тайм-ауте закрытие окна/отключение отправляет STOP.

Уставка должна находиться между технологическими пределами. Для одновременного изменения связанных параметров используйте FC16, передав весь нужный непрерывный диапазон, включая неизменённые промежуточные регистры. Сначала строится копия конфигурации, затем проверяются границы и связи; при ошибке не меняется ни один регистр.

Приложение ПК не посылает START автоматически. Восстановление выполняет сама прошивка по EEPROM. После аварии или смены адреса прошивка сохраняет STOP; восстановление датчика или связи не возобновляет нагрев.

Holding 41 (`PREFERRED_MODE`: 0=STOP, 1=AUTO, 2=MANUAL) — выбор следующего режима в окне. Holding 42 — ручная мощность 0…10000 = 0…100 %. Изменение этих настроек не включает выход. Действующее состояние для восстановления находится в holding 45 (`POWERUP_MODE`). Команды 256 автоматически меняют 45 и запрашивают SAVE; команда 257 в MANUAL также сохраняет новую мощность в 42. Выход удерживается выключенным до завершения записи. Опросить input 37 до выхода из 1, проверить отсутствие 4 и ожидаемый input 4/61. При повторе неизменённого режима/мощности EEPROM не записывается.

После питания прошивка ждёт не менее 1 секунды, стабильного адреса и достоверных датчиков. При отсутствии ошибок восстанавливаются AUTO или MANUAL с мощностью 42. При ошибке калибровки/EEPROM, зафиксированной аварии или отсутствии готовности в течение 15 секунд восстановление отменяется и сохраняется STOP. После watchdog-reset фиксируется F_LOOP и нагрев не восстанавливается. Input 62 показывает ожидание/успех/отмену. Автономно восстановленный прибор работает без ПК; тайм-аут связи активируется первым успешным адресным запросом. Для дальнейшей автономной работы после отключения мастера установите COMM_TIMEOUT_MS=0. При явном запуске через Modbus контроль связи действует сразу.

## Первичный тест тока: команда 260, прошивка 2.4

При неподтверждённом ACS712 обычные AUTO/MANUAL заблокированы. Для сравнения с внешними токовыми клещами предусмотрен отдельный сервисный запуск: holding 260 = `0xCA10`. Он включает 100 % выхода максимум на **10 секунд**, затем переходит в STOP. Input 4 = 3 обозначает тест; holding 260 при чтении возвращает оставшиеся миллисекунды (0 вне теста). Holding 256 принимает только прежние 0/1/2; значение 3 не запускает тест.

Условия: сохранённый STOP, dirty=0, POWERUP_MODE=0, внутренняя компенсация, OUTPUT_LIMIT=100 %, достоверные свежие TC/ADC, устойчивый адрес, отсутствие зафиксированных и иных активных ошибок. На старте RMS ADC должен быть не выше 10 counts. Задавать калибровочный флаг заранее не требуется: тест не меняет CALIBRATION_FLAGS и не является подтверждением калибровки.

В тесте действуют штатные защиты и дополнительные ограничения: PV ниже 65 °C, сырой RMS ADC не выше 400 counts (предел не зависит от корректируемого gain/offset), успешный адресный обмен не реже одного раза в секунду независимо от COMM_TIMEOUT_MS. При недостоверном/просроченном датчике или другой аварии — STOP с фиксацией причины. Десятисекундный срок нельзя продлить повтором команды; повтор во время теста возвращает busy. STOP допустим в любой момент; переход в AUTO/MANUAL и запись ручной мощности во время теста запрещены. Реле «в допуске» и «после прогрева» в тесте не включаются.

Сервисный режим не записывается в EEPROM и не возобновляется после перезапуска. Его предел ADC соответствует только предварительной оценке около 8 А при номинальном масштабе ACS712 30 А; это не независимая аппаратная защита и не откалиброванный порог в амперах. Применение: короткая первичная проверка небольшой известной резистивной нагрузки с внешним измерителем, при наблюдении оператора. Нормальная эксплуатация по-прежнему требует калибровки и подтверждения bit0.

## Реле K1 и прогрев

Holding 43 выбирает одну функцию; 44 — время прогрева в секундах (0…65535, default 600):

| Значение | Реле включено, когда |
|---:|---|
| 0 | Никогда |
| 1 | Регулятор работает, ошибок нет, температура в допуске |
| 2 | Как 1, и закончилась выдержка прогрева |
| 3 | Есть любая текущая или зафиксированная ошибка |
| 4 | Есть F_OVERCURRENT |
| 5 | Есть F_OPEN_HEATER: недостаточный ток при включённом нагреве |
| 6 | Есть ошибка датчика/ADC, связи, адреса, watchdog/цикла, EEPROM, калибровки или ток при OFF; температурный предел, перегрузка и обрыв нагревателя исключены |

Функции 3…6 учитывают active OR latched и действуют также в STOP. K1 — сигнальное реле, не аварийный контактор. Выдержка начинается при первом попадании в допуск после запуска. Выход из допуска не сбрасывает время, но реле 1/2 выключается; после выдержки реле 2 включается только при нахождении в допуске. STOP, ошибка, изменение уставки/допусков/функции/времени сбрасывают таймер. После питания выдержка проходит заново. Input 58 — функция, 59 — состояние прогрева, 60 — оставшиеся секунды, 61 — режим восстановления, 63 — число настроек.

Для F_OPEN_HEATER задать holding 27 > 0 и 28 — накопленное время достоверных ON-окон с током ниже порога. OFF-время и смешанные окна RMS не учитываются; нормальный ON-ток и STOP сбрасывают накопление. Проверка требует полного 200-мс измерительного окна после переключения и участка не менее 250 мс; на очень коротких импульсах обнаружение не гарантируется. Порог 0 отключает диагностику.

## Сохранение

Holding 258 = `0xA55A` запрашивает сохранение. Нормальный ответ означает принятие команды, **не завершение записи**. Опросить input 37 до 2 (успех) или 4 (ошибка), тайм-аут 2 секунды. При сохранении доступны STOP и чтение, изменение конфигурации и запуск возвращают busy. Команда 258 разрешена только в STOP. Обычные записи holding 0/18/19 меняют RAM; команда 261…263 сохраняет рабочие значения вместе с текущим режимом.

Настройки хранятся в AT24C512BN, слоты `0x0400` и `0x0500`, по 256 байт. Формат: magic `TC2!`, версия uint16=5, число регистров uint16=47, номер uint32, 47 регистров uint16, CRC16 всех предшествующих байтов. Внутри EEPROM все многобайтовые поля, включая CRC, big-endian. Это отдельный формат, не RTU-кадр. При записи сначала инвалидируется новый слот, затем пишутся и проверяются данные; magic записывается последним. Старый слот остаётся целым. Выбор при старте — валидная запись с более новым номером с учётом переполнения uint32.

Конфигурации 2.0 (версия записи 2, 41 регистр) и 2.1 (версия 3, 43 регистра) загружаются с проверкой прежнего CRC. Новые поля получают функцию реле 1, прогрев 600 с и режим восстановления STOP; следующий SAVE создаёт версию 5. Записи версии 4 с 46 параметрами сохраняют прежний режим и калибровки, holding 46 получает 0. Старые периоды меньше 2 секунд повышаются до 2 секунд при миграции; остальные значения не меняются. Конфигурация исходной ssr_cpu_v1 не мигрируется. При отсутствии подходящей записи используются defaults, input 37=3, config_dirty=1, STOP. Автоматическое сохранение режима записывает всю текущую RAM-конфигурацию; обычные правки до команды SAVE/режима остаются в RAM.

## Аварии

`active_faults` — текущие причины запрета; `latched_faults` — сохранённые в RAM причины остановки, сбрасываемые отдельной командой. Обычные ошибки запуска (например, ещё нет измерения) не фиксируются автоматически до RUN. Перегрев/выход за температурный предел, перегрузка и ток при выключенном выходе фиксируются также в STOP. После перезагрузки история аварий в RAM теряется; журнал должен вести клиент ПК.

| Бит | Маска | Причина |
|---:|---:|---|
| 0 | 0x0001 | Недостоверная термопара / SPI / MAX31856 |
| 1 | 0x0002 | Нет свежей температуры |
| 2 | 0x0004 | ADC неисправен или отсчёты достигают границ шкалы |
| 3 | 0x0008 | Нет свежего RMS тока |
| 4 | 0x0010 | Внешняя компенсация вне диапазона либо петля недостоверна |
| 5 | 0x0020 | Нет свежего внешнего датчика, когда он выбран |
| 6 | 0x0040 | Температура вне технологических пределов |
| 7 | 0x0080 | Ток выше порога в течение заданного времени |
| 8 | 0x0100 | Ток при достаточно долго выключенном PA3 |
| 9 | 0x0200 | Нет тока при достаточно долго непрерывно включённом PA3 |
| 10 | 0x0400 | Истёк тайм-аут связи |
| 11 | 0x0800 | Недопустимый или ещё нестабильный адрес |
| 12 | 0x1000 | Основной цикл более 50 мс не обновлял управление при активном выходе; только latched |
| 13 | 0x2000 | Не подтверждена необходимая калибровка |
| 14 | 0x4000 | Ошибка записи/проверки EEPROM; нагрев остановлен, сохранение состояния не подтверждено |

Для input 31 младший байт — SR MAX31856: bit7 CJ range, bit6 TC range, bit5 CJ high, bit4 CJ low, bit3 TC high, bit2 TC low, bit1 OV/UV, bit0 open. Дополнительные значения: 0x100 — SPI/readback, 0x200 — тайм-аут DRDY. Не показывайте оставшуюся числовую температуру как актуальную при соответствующей аварии или истёкшем возрасте.

Сброс аварии допускается только при STOP и отсутствии активных причин. Возврат датчика или связи сам по себе не возобновляет нагрев. Ошибка EEPROM блокирует нагрев; после устранения причины повторить SAVE, проверить статус 2, затем сбросить зафиксированную ошибку. При неуспешной записи STOP последняя целая EEPROM-запись может содержать прежний режим — сохранение обязательно проверять до отключения питания.

## Ошибки Modbus и широковещательная остановка

| Exception | Значение |
|---:|---|
| 01 | Функция не реализована |
| 02 | Адрес/диапазон не реализован |
| 03 | Недопустимое значение, количество, byte count или связь параметров |
| 04 | Запуск/сброс аварии невозможен в текущем состоянии |
| 06 | Требуется STOP либо идёт сохранение |

Кадры с неверной CRC, короткие, переполненные, с нарушенными паузами или неверной фиксированной длиной отбрасываются без ответа. Проверка CRC никогда не блокирует дальнейший приём.

Адрес 0 поддерживает только **FC06/FC16 с одним регистром 256=0 (STOP)**, без ответа. Другие broadcast-команды игнорируются. Это намеренное ограничение реализации: широковещательные START, калибровка и SAVE не поддерживаются.

## Для будущего интерфейса ПК

Один запрос FC04 address=0 quantity=64 даёт полный снимок. Для начала достаточно выводить PV (16), CJ (17), внешний датчик (18), ток (22), мощность (21), mode (4), faults (8…11), ages (32…34), storage (37). Настройки интерфейса можно построить по `registers.json`, деля целые значения на `divisor` и учитывая `s16`. Показывать действующий адрес и обе hex-позиции переключателей. Переподключение к USB и смена адреса не должны посылать START автоматически.

Пример клиента на Python реализует FC03/04/06/16, CRC, проверку ответа и ожидание EEPROM. Его CLI только читает телеметрию либо выполняет явно заданный `--stop`; запуск нагрева доступен через явную запись режима в коде клиента.

Базовый формат функций и RTU проверялся по [Modbus Application Protocol](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf) и [Modbus Serial Line Guide](https://www.modbus.org/file/secure/modbusoverserial.pdf). Эта прошивка реализует описанное подмножество, без заявления о сертификации Modbus.


## Период ШИМ 2–300 секунд

Период в миллисекундах = `(holding[46] << 16) | holding[13]`, допустимо 2000…300000. Например 300 секунд: holding 46=4, holding 13=37856. В STOP обновить обе части атомарной FC16-записью 0…46, затем SAVE. Запись только младшего слова 13 обнуляет старшее слово для совместимости коротких периодов. Период в таймере 32-битный; длительность ON = period_ms × power_100 / 10000, наибольшее произведение 3 000 000 000 помещается в uint32. Это пакетное управление долей времени, не фазовое управление углом. PID и период пользователь выбирает под объект; прошивка не содержит модели воды или конкретного нагревателя.

Допуски — независимые положительные величины 0…1800 °C относительно уставки: нижняя граница SP−LOW, верхняя SP+HIGH. Поэтому при SP=100 °C и LOW=HIGH=100 °C полоса допуска 0…200 °C. Технологические пределы аварии задаются отдельно; допуск их не отменяет.

## Сохранить рабочие значения без смены режима

FC16 address=261, count=3, payload=[SETPOINT_C10, TOLERANCE_LOW_C10, TOLERANCE_HIGH_C10]. Другой размер и broadcast отклоняются. Все три значения проверяются и применяются атомарно, AUTO/MANUAL/STOP остаётся прежним. Изменение запускает запись всей текущей конфигурации EEPROM; повтор без изменений и dirty=0 не изнашивает память. На время записи выход выключен, после записи прежний режим продолжается. Проверить input37=2, input36=0 и перечитать параметры. Ошибка EEPROM сохраняет запрет выхода и фиксирует F_STORAGE. Тестовый режим 3 и незавершённое сохранение возвращают busy. FC03 261…263 читает эти же рабочие значения.
