# Аппаратная привязка

Основание: существующий `ssr_cpu_v1`, схема управления из шести листов и силовая схема исходного проекта. MCU STM32F030C8T6: Flash 64 КБ, SRAM 8 КБ. Тактирование сохранено: внешний генератор 8 МГц на PF0, HSE bypass, PLL ×12 /2 = 48 МГц; ADC HSI14, IWDG LSI.

| Узел | Выводы и настройки v2 |
|---|---|
| Ток | PA1 / ADC_IN1, ADC 12 бит, TIM3 TRGO 5000 Гц, DMA circular 1000 × uint16 |
| Нагрев | PA3, активный HIGH, GPIO; программный пакетный цикл с проверкой жизнеспособности основного цикла |
| K1 | PB15, активный HIGH; температура в заданном окне при RUN |
| MAX31856 | PA4 CS, PA5 SCK, PA6 MISO, PA7 MOSI; SPI1 mode3, 3 МГц |
| DRDY / FAULT | PB0 / PB1, активный LOW, внешние подтяжки |
| 4–20 мА | PA8 / TIM1_CH1, без внутреннего pulldown; 128 захватов периода по 48 МГц, первые два исключаются |
| EEPROM | PB10 SCL, PB11 SDA; I2C2, AT24C512BN, 7-bit адрес 0x50, страницы 128 байт |
| RS-485 | PA9 TX / PA10 RX, USART1, автоматическое направление MAX13487 |
| USB FT232 | PA14 TX / PA15 RX, USART2; PA15 больше не выход LOW |
| Адрес, младший hex Sa3 | PB3, PB4, PB5, PB6 = биты 0…3, активный LOW |
| Адрес, старший hex Sa2 | PB7, PB8, PB9, PB13 = биты 4…7, активный LOW |
| Внешний watchdog | PC13 WDI, импульсы после завершённых циклов программы |
| Микросекундные интервалы RTU | TIM14, 1 МГц; расширение 16-битного счётчика в SysTick и при чтении |

На схеме оба адресных переключателя — FR01FR16H-S на 16 позиций. Сохранены электрические биты и инверсия из рабочего старого кода, добавлены debounce, диапазон Modbus и остановка при изменении.

Физические выводы PA14/PA15 одновременно используются ROM-загрузчиком STM32 и новой программой для связи с FT232. После прошивки нужен обычный запуск Flash: BOOT0=0 и reset. По данной схеме Sa5.2 замыкает BOOT0 на GND, Sa5.1 подключает WDI. DTR/RTS FT232 на схеме не подключены к BOOT/reset. Для SWD PA14 занят USART2 после старта приложения; подключение отладчика требуется под reset либо сборка с отключённым USART2. PA13 прошивка не перенастраивает как обычный выход.

ADC DMA прерывания только отмечают завершённую половину буфера. Основной цикл проверяет последовательность и NDTR, суммирует две половины и публикует измерение. При потере половины текущий результат инвалидируется, увеличивается счётчик пропусков. Переполнение/ошибка ADC блокирует измерение до перезапуска устройства; молчаливого продолжения со старым током нет.

MAX31856 работает в однократном режиме. Внешняя температура CJ записывается перед запуском преобразования, затем CJ, TC и SR читаются одной операцией. Контролируются статусы SPI, readback конфигурации, DRDY, FAULT и возраст данных. Изменение типа/компенсации/поправок инвалидирует прежнее измерение до нового результата. AD7741 измеряется короткими DMA-захватами примерно каждые 50 мс; отсутствие фронтов вызывает тайм-аут и повторную попытку.

Выход PA3 имеет отдельный немедленный путь LOW. SysTick 1 мс снимает PA3 и K1 при отсутствии обновления управления более 50 мс, когда они активны. Это действует при работающих прерываниях. При выключенных прерываниях/жёстком зависании остаются аппаратные watchdog; IWDG номинально около 3 с при LSI 40 кГц. HardFault/NMI/Error_Handler непосредственно снимают выход. Время реального снятия тока у исправного симистора дополнительно зависит от ближайшего нуля тока.

С версии 2.3 проверка периодов AD7741 допускает интервалы от 180 до 2100 тактов TIM1 (48 МГц). При CLKIN=500 кГц нормальный короткий интервал двух тактов преобразователя занимает 192 такта TIM1. Прежняя нижняя граница 200 ошибочно отвергала такой поток, хотя его средняя частота могла оставаться в рабочем диапазоне. Согласно рис. 7 паспорта AD7741, интервалы синхронного потока меняются между целыми кратными CLKIN; усредняется вся серия. Проверка средней частоты 25…225 кГц и допустимого тока сохраняется. Отдельные сырые интервалы на стенде пока не снимались; исправление проверяется моделью такого потока, затем требует проверки на приборе.

## Ограничения существующего железа

На испытанном экземпляре 06.11.2026 диапазона RP1 не хватило: при 20 мА в упоре измерялось около 225,14 кГц. Пользователь заменил R17 с 62 кОм по исходной схеме на **47 кОм** и вернул RP1 на два оборота. После этого получено около 177,5 кГц при 20 мА. Калибровка EEPROM этого экземпляра — 372/1906 мВ; переносить её на другие платы без измерений нельзя. Исходная схема в архиве не изменялась. Подробные результаты — [VALIDATION.md](VALIDATION.md).

Прошивка не устраняет отмеченные в исходном аппаратном обзоре вопросы: запас уровня HIGH на PA8 после делителя, возможность насыщения тракта 4–20 мА, режимы питания и сигналов USB, изоляцию и тепловой режим силовой платы. В частности, снятие PA3 не отключит пробитый силовой симистор. **K1 не включён в силовую цепь как аварийный контактор.** Проверка независимого отключения и аппаратной термозащиты остаётся отдельной задачей стенда.

До подключения рабочей нагрузки необходимы физические проверки из [VALIDATION.md](VALIDATION.md). Сборка и native-тесты не подтверждают реальные электрические уровни, точность датчиков или работу с сетью.
