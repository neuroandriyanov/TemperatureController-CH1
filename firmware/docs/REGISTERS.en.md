# Register map 2.4

The source map is generated by `scripts/register_map.py` from `app/config.def`. All addresses are zero-based and numbers decimal. Value / divisor = physical quantity. Ranges and defaults below use the transmitted integer units. This English companion preserves the same addresses, types, scales and limits.

## Commands

| Address | Command | Values |
|---:|---|---|
| 256 (0x100) | Mode | 0 STOP / 1 AUTO / 2 MANUAL |
| 257 | Manual power | 0…10000 = 0…100.00% |
| 258 | Save EEPROM | 0xA55A |
| 259 | Reset fault | 0xC1EA, only in STOP with no active causes |
| 260 | Current test up to 10 s | 0xCA10; read returns remaining ms. Conditions and limits in PROTOCOL.en.md |

FC16 261…263: atomic setpoint, lower and upper tolerance (0.1 °C), saving EEPROM and retaining current mode. Check input 37=2 and dirty=0; writing briefly pauses output during EEPROM access.
