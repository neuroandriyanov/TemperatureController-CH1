# Происхождение публикационной копии

В `raw` находятся сохранённые измерительные записи 6–7 ноября 2026 года. Это копии после удаления привязок к компьютеру: абсолютных локальных путей, номеров COM, USB-идентификаторов, токенов и каталогов вывода. Численные отсчёты, время, конфигурации, флаги достоверности, ошибки и пропуски сохранены. Идентификаторы роли соединения могут заменять номера портов. Подготовительные и неудачные измерения сохранены для объяснения диагностики.

`source-manifest.json` содержит хеш исходного файла до очистки и хеш публикуемой копии для включённых измерительных файлов. Из-за очистки JSON форматирование и хеш изменились; этот факт не является изменением показаний. Переписка, handoff/session-файлы, личные Flash backups, список USB-устройств и приватные настройки программ не включены.

Фотографии — реальные кадры, без генерации ИИ, ретуши измерительных значений или замены экранов. Из JPEG удалены EXIF/IPTC и комментарии, из PNG — текстовые/EXIF chunks; пиксельные данные не пересчитывались. Авторские наложения, уже присутствовавшие в исходном кадре стенда, сохранены. В XLSX изменены только поля авторства контейнера; листы и формулы не изменены. PDF, Gerber и STL сохранены без изменения технического содержимого.

В подборке есть не все вложения исходных опытов. Поля исходных журналов могут упоминать непубликуемые снимки/служебные отчёты; такие ссылки не доказывают наличие файла. Список отсутствующих локальных вложений формируется в `omitted-attachments.json`. Сохранившиеся пары лежат в `photos`, первичные численные серии — в `raw`. Абсолютный путь, полностью удалённый при очистке, обозначен `[local file path omitted]`.

Повторно рассчитанные графики и статистика помещаются в `derived` и `plots`. Четыре отдельно проверенные термограммы не заполняют пропуски основного журнала: в производной записи указаны метод, ограничение палитры и ручная проверка отсутствия меню.
