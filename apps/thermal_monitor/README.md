# Стенд · Видео и тепло

Запуск: `python run.py thermal` из корня. Два независимых источника DirectShow: цветная камера/HDMI-карта и UTi260B. Программа рассчитана на Windows; зависимости перечислены в `requirements.txt`.

Цветное видео имеет регулируемые подавление бликов и повышение резкости. Эти настройки не создают радиометрические данные. Тепловизор поворачивается на 0/90/180/270°. Совмещение открывает прозрачный слой: четыре угла изменяют перспективу, центральная ручка задаёт поворот; результат сохраняется локально. После изменения крепления совместите заново.

Крестик показывает приблизительную температуру по палитре UTi260B и распознанной шкале. Сохранённая точка проецируется на цветное изображение. Кнопка сохранения создаёт цветной кадр с отметками, термограмму и JSON в `output/bench_monitor`. Исходные экранные показания и оценка в произвольной точке различаются.

## Управление для автоматизации

При запуске создаётся локальный API на 127.0.0.1, свободный порт 18765…18774 и случайный токен. `control.py` сам читает `.runtime/api.json`; не публикуйте этот файл. Примеры из папки приложения:

```text
python control.py state
python control.py devices
python control.py temperature 0.45 0.58
python control.py mark 0.45 0.58 --name A
python control.py save
python control.py frame thermal thermal.png --raw
```

Полный интерфейс: [API.txt](API.txt). Выбор устройств/режимов делается по реально полученному списку. Сохранённые настройки другого ПК не поставляются.

## Границы измерения

Это декодирование видеовыхода, не радиометрический SDK. `≈` обязательно: точность зависит от палитры, шкалы, излучательной способности, отражений, экрана и геометрии. Неизвестная палитра/нечитаемый OSD/меню приводят к отсутствию температуры. Эвристика меню иногда ошибочно срабатывает на тёмных областях обычной сцены; в опыте такие пропуски сохранены, отдельные кадры разобраны отдельно. Полноценное исправление требует тестовых кадров реального меню и обычной сцены; текущая публикация не объявляет его выполненным.

Карта захвата может продолжать отдавать кадры «NOT SUPPORT» после перегрева внешней камеры: факт получения кадра не подтверждает работоспособность оптики. Перед публикацией снимки проверяются визуально. Для анализа материала используйте [методику](../../measurements/README.md).

Для CLI-примеров из этой папки используйте `python ../../env.py` вместо `python`, чтобы запускать их в окружении, установленном общим setup.py.
