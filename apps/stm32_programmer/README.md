# Стенд · Прошивка STM32

**Русский** | [English](README.en.md)

Запуск из корня: `python run.py programmer`. Программа предназначена для STM32F030C8 с 64 КБ Flash через штатный UART ROM bootloader. Собственный Python-клиент протокола AN3155; установщик ST FlashLoader не требуется и не включён.

Открывает BIN и Intel HEX, показывает адреса и содержимое, проверяет векторы и диапазоны памяти. Порт выбирается вручную. По умолчанию предлагается текущий результат сборки `firmware/build/controller.bin`, если он существует. Пока файл не собран, откройте его после сборки или выберите собственный совместимый образ.

Операции: определение устройства, резервное чтение, стирание, запись с проверкой, сравнение с файлом, полный цикл «стереть → записать → проверить», запуск приложения. Перед стиранием/полным циклом сохраняется резервная копия. Неверный chip ID не допускается к стиранию. Результат и backup — `captures`; при ошибке сохранения backup стирание не продолжается. Отмена выполняется между пакетами и не гарантирует целую прошивку после прерванной записи.

CLI использует те же проверки:

```text
python app.py --ports
python app.py --operation probe --port PORT
python app.py --operation flash --port PORT --firmware ../../firmware/build/controller.bin
```

`PORT` замените своим UART-портом загрузки. Для команд без порта возникает ошибка, никаких предустановленных COM-номеров нет. BOOT0/RESET переключаются на плате. Полный порядок — [QUICKSTART](../../docs/QUICKSTART.md).

Для CLI-примеров из этой папки используйте `python ../../env.py` вместо `python`, чтобы запускать их в окружении, установленном общим setup.py.
