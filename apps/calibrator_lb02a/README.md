# LB02A · экран и управление

Запуск из корня: `python run.py calibrator`. Приложение Tkinter отображает реальный экран LB02A и передаёт нажатия кнопок через собственный **мост ESP32-S3**. Это не штатный USB-протокол калибратора. Без установленного моста приложение не сможет управлять обычным LB02A.

## Мост

Проверенная конфигурация: ESP32-S3 DevKitC-1, Flash 16 МБ, Arduino через PlatformIO `espressif32@6.10.0`. Исходники находятся в `bridge/src`; номер порта загрузки не задан. После `python setup.py --dev` из корня:

```text
python env.py -m platformio run --project-dir apps/calibrator_lb02a/bridge -e display-keypad-emulate
```

Это только сборка. Для осознанной загрузки в **свой мост**, добавьте `--target upload --upload-port PORT`. Среда `display-capture` предназначена для чтения дисплея без эмуляции клавиш. Питание/уровни сигнала и модификацию прибора проверяют до подключения; повторяйте соединения по фотографиям и схеме вкладки «Подключение платы».

| ESP32 | Соединение |
|---|---|
| GPIO12 | SCL дисплея, ориентир RCS |
| GPIO11 | SDA дисплея, ориентир LED |
| GPIO9 | 9341-DC |
| GPIO6 | 1650-SCL |
| GPIO5 | 1650-SDA **на стороне контроллера LB02A** |
| GND | Общий провод |

Для эмуляции SDA между TM1650 (вывод 3) и контроллером LB02A размыкается переключателем. GPIO5 подключён к стороне контроллера. Не соединяйте два активных источника SDA. Вкладка с четырьмя фотографиями включена в программу. Штатный код самого LB02A не входит в комплект.

## Подключение

Выберите USB-порт моста и подключитесь. Поток дисплея — 4 000 000 бод. Wi-Fi вариант использует TCP 8769, типовой адрес AP 192.168.4.1. Имя точки и пароль формируются мостом для конкретного устройства; личные пароли в исходниках отсутствуют. При запуске без аргументов программа не подключается сама.

CLI для явного соединения: `python esp32_display_viewer.py --port PORT`. Снимок: добавьте `--snapshot screen.png --seconds 5`. Для локального API добавьте `--control-port 8768`; доступ только с loopback, не публикуйте этот порт через сеть.

API: `GET /state`, `GET /frame.png`, `POST /key` с JSON `{"key":1}`. Кнопки 1…16, кроме питания 13. Ответ 202 означает постановку в очередь, а не подтверждение режима. Перед следующим шагом проверьте свежий экран и распознанное значение; разрыв потока/пропуски пакетов инвалидируют показание. Модуль `lb02a_reading.py` обрабатывает эту свежесть; тесты не открывают прибор.

USB моста может создать общую землю с измерительной цепью. В опыте Pt100 использовали автономное питание калибратора и ручное переключение точек; это задокументировано, а не скрыто программной поправкой.

Для CLI-примеров из этой папки используйте `python ../../env.py` вместо `python`, чтобы запускать их в окружении, установленном общим setup.py.
